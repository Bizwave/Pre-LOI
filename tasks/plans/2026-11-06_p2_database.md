## Goal
The pipeline gets a memory: a database in the data folder (outside the repository) holding customers,
deals and every status change, the documents received, their pages, and pipeline runs. The structure is
created only by migration scripts, and the rest of the code writes to it only through a small set of
repository functions that enforce the deal status flow.

**Done when:** `python -m bizwave_preloi.db upgrade` creates `<data folder>/bizwave.db` with the six
tables; a deal can be created, moved through the status flow (illegal moves refused), given documents
(hashed, de-duplicated, stored relative to the deal folder) and pages from the PDF inventory, and a
pipeline run can be started and finished; the migration round-trips; the whole suite passes.

class DecimalText(TypeDecorator):      # impl String(40); cache_ok = True
    # bind: Decimal or int -> str(Decimal(value)) exactly as given; float -> TypeError; None -> None
    # result: str -> Decimal
class UTCDateTime(TypeDecorator):      # impl DateTime(timezone=True); cache_ok = True
    # bind: aware datetime -> converted to UTC; naive -> ValueError; None -> None
    # result: always an aware datetime in UTC (SQLite returns naive; tzinfo=UTC is attached)

# db/models.py  (SQLAlchemy 2 declarative, Mapped[...] annotations)
NAMING_CONVENTION = {"ix": "ix_%(column_0_label)s", "uq": "uq_%(table_name)s_%(column_0_name)s",
                     "ck": "ck_%(table_name)s_%(constraint_name)s",
                     "fk": "fk_%(table_name)s_%(column_0_name)s_%(referred_table_name)s",
                     "pk": "pk_%(table_name)s"}
class Base(DeclarativeBase): metadata = MetaData(naming_convention=NAMING_CONVENTION)
