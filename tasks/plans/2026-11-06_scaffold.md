## Data contracts
- `schemas.Statement` / `LineItem` / `Period` / `SourceRef`: what ingestion (Day 3) must produce.
- `schemas.AddBack`: seller add-backs; `rule_id`, `classified_by`, `lender_view` set by `classify`.
- `finance.Earnings` + `finance.Structure` -> `finance.Evaluation` / `MaxPrice` / `SensitivityRow`.
- `llm.ask(use, content, answer_shape)` -> instance of `answer_shape` or None; run-log record per call.
- `validate.check_statement(Statement)` -> `FootingReport` (`failures`, `watches`, `not_checked`, `ok`).
