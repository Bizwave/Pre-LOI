## Goal
One place that says where things live and how Claude is switched, read by every module. Client files,
the run log and (from P2) the database live in a data folder **outside the repository**, by default
`C:\Users\<you>\BizWaveData` (`~/BizWaveData` on a Mac). A `.env` file in the repo folder is read
automatically, but never overrides a real environment variable and is never read during tests.

**Done when:** with nothing configured, the app resolves every path to `~/BizWaveData/...`; a data
folder inside the repository is refused with a clear message; the run log is written to the data
folder; Claude's on/off switches and model come from the settings; and the whole suite passes with a
temporary data folder and no `.env` loaded.

    disabled_uses: frozenset[str]  # BIZWAVE_LLM_DISABLED_USES: comma list, spaces trimmed, blanks dropped
    llm_model: str               # BIZWAVE_LLM_MODEL; default "claude-sonnet-5-5"
    has_api_key: bool            # ANTHROPIC_API_KEY present and non-blank. The key itself is never stored.

def ensure_data_dirs(s: Settings | None = None) -> Settings
