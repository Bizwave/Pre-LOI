Write lessons for the packet or session just finished to `tasks/lessons.md`.

1. Review what happened: research findings, plan revisions, gate first run, build friction,
   gate-runner results, review findings and corrections.
2. Add a new entry at the TOP of the file (newest first), in this format:

```
## <Packet id and one-line description> (YYYY-MM-DD, branch `<branch>`)

### For You (Chan)
- <what Chan should know, check or do differently: product, process, decisions, things to verify>

### For Claude Code (Me)
- <a specific rule for future sessions: when it applies and what to do>
```

Rules
- Two to six lessons per category. Specific beats general: name the file, rule or test.
- Include every review blocker and what it taught.
- Append only; never rewrite earlier entries.
